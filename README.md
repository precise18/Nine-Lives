# 🐱 Nine Lives - The Word Guessing Game

A challenging terminal-based word guessing game where you have exactly 9 lives to uncover the secret word. Built with pure Python, this game tests your vocabulary and deduction skills.

## 🎮 Game Overview

In Nine Lives, you're presented with a hidden word and must guess it one letter at a time - or risk it all by guessing the entire word. Each incorrect letter costs one life, while a wrong word guess costs two lives. Choose your strategy wisely!

## ✨ Features

- **Three Difficulty Modes**
  - 🟢 Easy: 12 lives, short 3-5 letter words
  - 🟡 Normal: 9 lives, medium-length words
  - 🔴 Hard: 7 lives, challenging vocabulary

- **Gameplay Mechanics**
  - Guess individual letters or the entire word
  - Visual hangman display shows your progress
  - Track guessed letters to avoid repeats
  - Play again option for endless fun

- **Visual Elements**
  - Color-coded feedback messages
  - ASCII art hangman display
  - Clear game state interface
